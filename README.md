# 런앤로컬 · 생활 목적지 러닝

오늘의 목적지까지 이동을 사용자의 시간·거리·페이스에 맞는 러닝으로 전환하는 공익적 러닝 챌린지입니다. 현재는 **서울 성수·서울숲·뚝섬 실증권역**만 지원합니다.

카카오 장소 검색으로 목적지를 입력하고, OpenStreetMap 보행망에서 실제 경로를 생성합니다. 정해진 예시 코스의 점수만 바꾸는 방식이 아닙니다.

## 실행과 검증

Node.js 24를 권장합니다.

```bash
npm ci
npm run dev
npm run lint
npm test
npm run build
```

카카오 검색에는 `KAKAO_REST_API_KEY`가 필요합니다. 키가 없거나 API가 실패하면 저장된 POI를 보조 목록으로 사용합니다. 배경지도 타일은 인터넷 연결이 필요합니다.

## 주요 흐름

1. 출발지를 검색·현위치·지도에서 선택합니다.
2. 오늘 가야 하는 식사·쇼핑·문화·생활 목적지를 먼저 검색합니다.
3. 목적지가 없을 때만 생활 미션을 열고, 사용자가 미션을 선택하면 장소를 추천합니다. 성별·연령대 입력 시 집계 군집에 따라 메뉴 순서만 바뀝니다.
4. 목표 거리·페이스·시간·코스 형태·테마·제외 조건을 적용합니다.
5. 보행망 연결·시간·거리 조건을 통과한 코스만 최대 3개 보여줍니다.

## Destination Type과 군집별 생활 미션 메뉴

카카오 카테고리를 `MEAL`, `SHOPPING`, `DAILY_ERRAND`, `CULTURE_LEISURE`, `SOCIAL_NIGHT`, `SPORTS_WELLNESS`, `CAFE_DESSERT`로 분류합니다. `REVIEW`와 `EXCLUDE`는 장소 추천에서 제외합니다.

신한카드 Destination Type 분석은 개인 이동이나 선호를 예측하는 모델이 아닙니다. 서울 집계 소비패턴은 생활 미션 메뉴 구성의 근거로 사용합니다. 같은 미션의 모든 후보에 동일하게 더해 순위에 영향을 주지 않던 Context 보너스는 제거했습니다. 목적지 추천은 장소 적합도 35% + 경로 점수 65%에서 조건 완화 감점을 적용합니다. 테마·풍경 완화 또는 순환→왕복 변경은 선택 전에 카드에 표시합니다.

성별·연령대는 선택 항목으로 기기에만 저장합니다. 분석팀이 전달한 4개 집계 군집 매핑을 조회해 목적지가 미정인 화면의 메뉴 순서와 `먼저 둘러보기` 표시에만 사용합니다. 개인을 새로 군집화하거나 개인 선호를 학습하지 않습니다.

| 집계 군집 | 입력한 성별·연령대 | 먼저 보여주는 미션                |
| --------- | ------------------ | --------------------------------- |
| 0         | 여성 20대          | 생활 목적지 러닝                  |
| 1         | 여성 30·40·50·60대 | 쇼핑 목적지 러닝                  |
| 2         | 남성 20대          | 식사·카페 러닝                    |
| 3         | 남성 30·40·50·60대 | 생활 목적지 러닝·쇼핑 목적지 러닝 |

두 항목 중 하나라도 미입력이면 기본 순서(생활 → 쇼핑 → 식사·카페 → 문화생활)를 사용합니다. 모든 메뉴를 제공하며 미션은 자동 선택하지 않습니다. 사용자가 직접 고른 미션·목적지는 프로필을 변경해도 유지합니다. 성별·연령대·군집 ID는 장소 검색 API나 경로 점수로 전달하지 않습니다.

군집 2의 근거는 MEAL입니다. 전달 자료의 `저녁 약속 러닝`은 현재 앱의 `식사·카페 러닝`에 연결하며, 카페는 실제 권역 POI 후보로만 포함합니다. 카페 선호나 저녁 약속을 추론하거나 별도 가점을 주지 않습니다. 별도로 분석한 3개 요일·시간대 Context 군집은 이번 메뉴 정렬에 사용하지 않습니다.

## 데이터와 한계

- `public/data/seongsu.json`: 성수·서울숲·뚝섬 실증권역 보행 도로망
- `lib/destination-context.ts`: Destination Type, 미션 라벨, 분석용 Context prior 메타데이터(점수 미사용)
- `lib/destination-recommender.ts`: 4개 집계 군집의 메뉴 매핑, 장소 후보 점수 계산(별도 함수)
- `lib/recommender.ts`: 경로 탐색·하드 제약·순위 계산
- `tests/seongsu-coverage.ts`: 실증권역 도로망 연결성 검증
- `tests/destination-context.ts`: 분류·미션 라벨 검증
- `scripts/add-terrain-elevation.py`: 공개 지표면 고도 타일 결합 및 추정 경사 생성

실제 상점 입구·영업 여부·공사·야간 조명·현장 통행 가능 여부는 방문 전 확인해야 합니다. 추천 점수는 안전·성공 확률이 아닙니다.
